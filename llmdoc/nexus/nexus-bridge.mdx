# Nexus 桥（配对、通道、关闭次序）

## 凭据策略（单一来源不变量）

与远端 NexusDock 节点（手机/远端控制面）的双向通道。配对：`POST <endpoint>/v1/nodes/pair`
用一次性配对码换 Device Token，写入配对身份文件（Version 1：Endpoint/NodeID/DeviceID/DeviceToken）。

> **Nexus 地址与 Device Token 只来自配对身份文件**；拒绝环境变量/控制面板等第二来源
> （启动时还会主动清除旧 env，见 execution-model）；旧 DPAPI Token 不再读取并立即清除。
> `Status` 输出刻意不含 token 本身。
> 节点 WebSocket 会在身份文件出现或变化后续上，不必为了拨入重启进程。Recall 等按启动配置注册的工具仍要重启后才出现。

## 协议边界

- WebSocket 客户端（消息上限 16MiB，与两边 Streamable HTTP `/mcp` 的请求体相同）；**应用层协议在外部模块 `github.com/uvwt/agentdock-protocol`**，
  本仓库侧边界是窄接口 `NodeAPI`：ToolNames/ToolDescriptors/UIResources/ToolContractHash/
  AgentDockLocalContext/Invoke/ReadAppResource。
- 远端经 Bridge 调到的能力与 Runtime API 共享同一契约（见 tool-system/runtime-api）；
  演化提案只能 propose（见 task-evolution/evolution-policy）。

## 生命周期与关闭次序

- 重连退避 1s→30s 指数 + 随机抖动；`ConnectionState` 供 `service.status`/控制面板展示。
  出站仍是默认通道。服务模式 `tailcat` 时，Tailcat 监听在已配对时接受节点 WebSocket；
  409、连接串和会话重叠见 nexus/tailcat-dial-in。收到 `TAILCAT_NODE_DIAL` 后退避停在
  30 秒探测，不再退回 1 秒。入站会话全部结束后立刻再探测一次。连接状态按活会话计数，
  这次 409 不会把仍在的入站标成断开。还有活会话时不提前探测。
- Invoke 需 drain（5s）再退出。
- **Bridge 必须先停接收并 drain，再允许外层关闭 Runtime**（`bridgeWG.Wait()` 先于
  `Runtime.Close`，见 execution-model 的启动/关闭编排）。

## nexusclient（共享 HTTP 传输策略）

与已配对 NexusDock 的通用 HTTP 传输：Bearer token、**token 不跨重定向传播**、有界响应体。
消费方：`internal/tool/recall`（memory）与 `internal/tool/task` 的 nexus transport——
领域路径/超时/错误语义归调用方所有，本包不拥有业务语义。
